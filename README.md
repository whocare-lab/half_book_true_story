## 🎯 這是什麼？

這是配合元智大學 學務處諮商與就業輔導組 **【半本真人故事書｜木匠之子的品管路，對、錯？】** 真人圖書館講座所製作的延伸閱讀網頁。

講座由一位 **56歲品管資深部門主管**（27年科技業現場經驗、元智大學 DBA 博士生）主講，透過「六個付過學費的選擇」帶領學生走過職涯從求職、選工作、職場前三年、中期倦怠到 AI 世代的完整地圖。

本網頁將講座中提到的 **1111 人力銀行職涯專欄文章**，依「六站架構」重新編排，方便學生課後分段閱讀、對照自身處境。
